# 误差传播台（error-propagation）

把每个测出来的量连同它的误差填进来，本页用**前向自动微分**求出结果的偏导，再按一阶传播算出：结果是多少、**还有多少不确定度**、**哪一项测量贡献最大**、**要达标必须先把哪个量测准**。

- 在线体验：https://xululu0401.github.io/error-propagation/
- 单文件交付：`index.html`（内联 `core.js` 与 `ui.js`，无外部依赖、不联网）
- 测试：`node --test tests/core.test.cjs`
- 构建：`node build.cjs`（由 `template.html` + `core.js` + `ui.js` 生成 `index.html`）

核心口径：σ_f = √Σᵢ (∂f/∂xᵢ · σᵢ)²；偏导由对偶数前向自动微分精确求出（不是差分近似）。
另有 2ⁿ 角点扫描与固定种子蒙特卡洛作为对照（用来检验「小误差 + 近似线性」的假设是否成立）。

边界：假设各变量误差互相独立；不做量纲检查；不处理相关误差（同一把尺子/同一次读数）与系统误差；
角点扫描不是严格区间上下界；蒙特卡洛是模拟，不是实测分布。默认样例与内置场景均为**虚构示例**，
不代表任何真实测量或仪器精度。

口径与假设见页面内「算法与使用边界」，与 `../需求与调研.md` 一致。
